Do not change, rename or delete any files from this folder.

You can move the whole folder to an other place,

but do not detach the files from the executable file!


In order to be able to open the help file, the whole program

folder has to be located under an ASCII only (English) path.


If the simulation or record hotkeys are not working outside

of the program, rerun it as administrator and try again.


Many of the program's functions won't work without admin

rights. It's highly recommended to run this program as

administrator.
